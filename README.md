## 🌌 Overview

**Galactic Space Game** is a lightweight, high-performance web MMORPG/strategy game where pilots command fleets, harvest volatile planetary resources, and survive severe cosmic environments.

### Key Features
* 🛸 **Fleet Command Center:** Customize, deploy, and manage multi-class space vessels.
* 🌋 **Dynamic Environmental Hazards:** Navigate lava planets, radiation belts, and extreme heat waves that drain ship hulls and pilot stamina.
* 👨‍✈️ **Pilot & Gear Customization:** Equip tactical suits with thermal shielding and specialized crew abilities to survive hostiles and hazards.
* ⚡ **Optimized Tick Engine:** Runs on a low-latency 1Hz simulation loop built for smooth gameplay across devices.

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** React, TypeScript, Zustand (State Management), HTML Canvas
* **Backend:** Node.js, Express REST API
* **Database:** MySQL
* **Deployment:** GitHub Pages (Client), Cloud Server (API)

---

## 🎮 How to Play

1. **Launch the Game:** Visit the live link above to jump straight into the browser app.
2. **Assign Your Crew:** Outfit your pilot with environmental hazard gear before entering high-temp sectors.
3. **Manage Your Fleet:** Balance attack, defense, and shield stats to handle planetary threat levels.
